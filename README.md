# File converter, from .md to .html

Simple file converter written in c#, it translates files in .md format into correct HTML 5 syntax.

Supported right now are:
- lists
- headers
- italic and strong paragraphs
- blockquotes
- images

In the future, supported will be:
- code elements
- tables
- horizontal rules
- links

In the future, it will probably also be able to convert files from the html into .md
